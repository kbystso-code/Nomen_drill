# Nomen Drill

ドイツ語の基本名詞の性（der / die / das）を反復練習するWebアプリです。HTML / CSS / Vanilla JavaScriptのみで構成し、外部ライブラリやビルド処理は使用しません。iPadで子供がタッチ操作しやすい、大きな文字とボタンを使用しています。

## 現在の機能

- 1セット40問。回答後に正誤と正しい冠詞を表示し、「Nächste Aufgabe」で次へ移動
- 通常40問は原則der / die / dasを13・13・14問に調整（繰り越しを優先）
- 回答の変更や連打による重複加算を防止
- 通常問題の進捗、正解数、正答率、間違えた問題の一覧を表示
- 間違い一覧には各回答と正解、JSONにあれば意味も表示
- 間違えた名詞を1回だけ復習。同じ名詞を何回間違えても復習は1問
- 復習で再度間違えた名詞だけを次回冒頭に優先出題
- localStorageによる繰り越し保存
- 全問正解なら復習を省略し、繰り越しを空にする
- 最終結果から「Noch einmal 40 Aufgaben」で新しいセットを開始
- 操作・説明・エラーはドイツ語。現在の200語には意味フィールドはありません

## 出題と復習の仕組み

通常問題・通常結果・復習・最終結果を別の状態として管理し、通常と復習の回答履歴も分けています。

40語以上あればセット内の名詞は重複しません。繰り越し名詞を先頭に確保して冠詞ごとの数を数え、残りの名詞をder / die / dasの3グループに分けてシャッフルします。在庫がある冠詞のうち出題数が最も少ないものから1語ずつ選び、合計40問にします。同数の冠詞の優先順はセットごとにランダムに決めるため、14問になる冠詞は固定されません。最後に繰り越し以外の部分をシャッフルします。

現在の200語では、繰り越しによる制約がなければ13・13・14問になります。繰り越しを減らして均等にすることはありません。例えばderが16語繰り越された場合はder 16・die 12・das 12問になります。特定の冠詞の語彙が不足する場合も、名詞の重複回避を優先し、残りの在庫から補います。

40語未満の場合は従来どおり全名詞をランダムな順で1回ずつ出し、使い切るたびにシャッフルして40問まで続けます。この場合は冠詞の均等配分より全語の一巡を優先します。名詞が2語以上あれば周回の境界も同じ名詞が連続しないようにします。

通常問題の不正解は回答ごとに一覧表示しますが、復習キューは名詞文字列で重複を除外します。復習で間違えてもキューには追加しません。正答率は通常40問を分母とし、小数第1位まで表示します。

## 保存について

localStorageのキーは `nomenDrillCarryover`、値は `['Tisch', 'Kind']` のような名詞文字列の配列をJSONにしたものです。実際のJSON文字列では二重引用符を使用します。

セット完了時に、今回の復習で不正解だった名詞だけで置き換えます。復習で正解した名詞は残しません。次回起動・再学習時に `nouns.json` と照合し、削除された名詞・重複・不正な値を除外して40問の先頭に入れます。現在の問題番号・回答履歴・得点は保存しません。途中でページを閉じた場合は前回完了時の繰り越しを維持します。

保存は同じブラウザ・同じオリジン（プロトコル、ホスト、ポート）で維持されます。別端末・別ブラウザには同期されません。ブラウザのサイトデータ削除やプライベート閲覧の終了などでは失われる場合があります。保存できない場合はドイツ語で通知し、そのページを開いている間はメモリ内の繰り越しで続行できます。

データはトップレベルの `nouns` 配列で管理します。現在は `noun`、`article` の2項目のみを持ち、今後 `plural`、`category`、`difficulty`、`phase`、`example` などを追加できます。

## 起動方法

JSONをfetchで読み込むため、HTMLを直接開かずHTTPサーバーを使います。

```sh
cd /Users/toshio/GitHub/Nomen_drill
python3 -m http.server 8000 --bind 0.0.0.0
```

Macで `http://localhost:8000` を開きます。終了はターミナルで Ctrl+C を押します。

iPadはMacと同じWi-Fiに接続し、Safariで `http://<MacのLAN内IPアドレス>:8000` を開きます。MacのIPアドレスはシステム設定のネットワーク詳細で確認できます。

## 動作確認

macOSでは追加インストールなしで回帰テストを実行できます。

```sh
python3 tests/run_tests.py
```

実際の `app.js` をJavaScriptCoreで実行します。DOMとlocalStorageはテスト用の代用品を使うため、ブラウザの実際の描画や永続ストレージ自体の検証は含みません。学習フローの6ケースに加え、出題バランスの7ケース（300セットの13・13・14配分、14問になる冠詞の変化、重複回避、繰り越し優先、偏り補正、復習・保存との連携）、連打、語彙数1・2・10・39・40・60の場合の周回と重複回避、破損した保存値、保存拒否も確認します。テストは実際のブラウザの保存データを変更しません。

ブラウザでの確認手順：

1. 全40問を正解する → 「40 / 40」「100 %」、復習なし、次回用0語。
2. 最初の5問だけ間違え、残りを正解する → 5語を復習。全て正解する → 次回用0語。
3. 同じく5問間違え、復習の2問だけ間違える → 復習は5問で終了、次回用2語。
4. 「Noch einmal 40 Aufgaben」を押す → その2語が先頭、全体は40問。
5. 同じURLを再読み込みする → 同じ2語が先頭。前回途中の進捗はリセット。ブラウザを閉じて再度開いても確認する。
6. 現在の200語では通常40問で同じ名詞が重複しないことを確認する。40語未満で同じ名詞を複数回間違えた場合の復習の重複除外は自動テストで確認します。

必要なら開発者ツールで `localStorage.getItem('nomenDrillCarryover')` を読み、保存配列を確認できます。iPadの縦・横向きや狭い画面で、ボタンの押しやすさと長い結果一覧のスクロールも確認してください。
